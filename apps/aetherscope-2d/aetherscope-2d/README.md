# AetherScope 2D - Sacred Geometry Synthesizer

A modular, React + TypeScript + p5.js kaleidoscope application featuring 12 sacred geometry patterns, 7 color palettes, and interactive controls.

## Features

- **12 Pattern Library**: Golden Spiral, Flower of Life, DNA Helix, Metatron's Cube, Koch Snowflake, Sierpinski Triangle, Fibonacci Squares, Lorenz Attractor, Mandelbrot Edge, Tesseract (4D), Bell Curve, and Free Draw
- **7 Color Palettes**: Neon, Pastel, Fire, Ocean, Monochrome, Sunset, Cosmic
- **Kaleidoscope Symmetry**: Adjustable mirror count (3-24)
- **Interactive Drawing**: Touch and mouse support
- **Autoplay Mode**: Automated pattern generation
- **Export**: Save creations as PNG images
- **Responsive Design**: Works on all devices
- **State Persistence**: No accidental resets

## Technology Stack

- React 18 + TypeScript
- Vite (build tool)
- p5.js (canvas rendering)
- Zustand (state management)

## Getting Started

Install dependencies:
```
npm install
```

Start development server:
```
npm run dev
```

Build for production:
```
npm run build
```
